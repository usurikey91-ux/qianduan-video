# 第一版真实验收清单

目标只验证最短闭环：添加对标账号 → 采集公开作品和互动数据 → 保存快照 → 按账号自身基线判断热度 → 进入待分析列表。

## 环境准备

- [ ] 已创建项目虚拟环境并安装 `requirements.txt`
- [ ] 已创建本机 `conf.py`（不提交）
- [ ] 工作台后端和前端可以启动
- [ ] OpenCLI Admin API 和前端可以启动
- [ ] OpenCLI Admin 不暴露公网
- [ ] 未配置 AI 时，基础采集流程仍可使用
- [ ] 未配置视频解析服务时，基础采集流程仍可使用

## 空状态

- [ ] 不添加任何账号时，工作台正常启动
- [ ] 对标账号页面显示空状态，而不是报错或伪造数据

## 第一平台真实账号

- [ ] 手动添加一个公开对标账号
- [ ] 能识别或选择平台
- [ ] 采集服务保存稳定账号 ID 和作品链接
- [ ] 首次采集保存公开数据快照
- [ ] 明确记录实际返回字段：发布时间、点赞、评论、收藏、分享等
- [ ] 未返回的字段显示为空/不可用，不填入猜测值

## 快照和热度

- [ ] 第二次采集生成新的数据快照，而不是覆盖首份快照
- [ ] 热度判断显示账号自身基线和计算依据
- [ ] 达到条件的作品进入待分析列表
- [ ] “特别火”只提高处理优先级，不改变分析规则和生成数量

## 失败和降级

- [ ] 平台没有适配器时，显示“不支持该平台”，不显示采集成功
- [ ] 账号失效、登录态失效、字段缺失、采集失败、发布时间缺失均有明确状态
- [ ] AI 未配置时，采集、快照和热度判断仍可用
- [ ] 视频解析服务未配置时，采集、快照和热度判断仍可用

## 记录

每次验收记录：平台、账号主页、采集时间、实际字段、失败信息、样例作品链接、热度判断结果。Cookie、Token 和本机路径不进入表格或仓库。
